# Tech Knowledge Base

## What is RAG?
Retrieval-Augmented Generation (RAG) combines document retrieval with text generation to produce more accurate responses.

## What is LangChain?
LangChain is a framework for building applications powered by large language models.

## What is an API?
An API (Application Programming Interface) allows different software systems to communicate.

## What is a Vector Database?
A vector database stores embeddings and enables similarity search.

## What is Groq?
Groq provides ultra-fast inference for large language models.
