# AI Compliance Monitoring – Data Fetcher Agent

This project implements an AI agent using LangGraph that retrieves operational data
from internal datasets and generates regulatory compliance metrics.

## Setup

Install dependencies:

pip install -r requirements.txt

## Run the agent

python main.py

## Output

The system generates regulatory metrics such as:

- Total transactions
- Flagged transactions
- Pending KYC customers
- High-risk customers
- Account statistics
